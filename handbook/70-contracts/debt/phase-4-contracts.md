# Contractهای بستن بدهی

## Phase Plan contract

Agent قبل از کدنویسی باید هدف، دامنه، taskهای <=۴ ساعت، تست، migration، ریسک و rollback را بنویسد.

## Implementation Report contract

هر task باید تغییرات، تست‌ها، امنیت، observability و بدهی باقی‌مانده را گزارش کند.

## Status contract

هر artefact باید یکی از این statusها را داشته باشد:

```text
SPEC | SKELETON | INTEGRATION-READY | IMPLEMENTED | PRODUCTION-READY
```
